# JavaScript Form Validation

A simple User Registration Form created using HTML, CSS and JavaScript.

## Features

- Name validation
- Email validation
- Password validation
- Minimum 6 characters password validation
- Alert messages for validation
- Form reset after successful submission

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Structure

- index.html – Structure of the form
- style.css – Styling of the form
- script.js – Form validation logic

## How It Works

The form takes the user's name, email and password as input.

JavaScript validates the entered details and displays an alert message if any field is empty or if the password contains less than 6 characters.

If all details are valid, the form is submitted successfully and the form fields are reset.
